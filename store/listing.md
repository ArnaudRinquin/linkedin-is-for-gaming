# Chrome Web Store listing

## Name

LinkedIn is for Gaming

⚠️ Trademark note: the name contains "LinkedIn". The Chrome Web Store sometimes
rejects extensions whose *name starts with* a trademark. Safer fallback names if
rejected: "Games Only — for LinkedIn", "Gaming-Only LinkedIn". Mentioning
LinkedIn in the description is fine; claiming affiliation is not.

## Short description (max 132 chars)

LinkedIn, minus LinkedIn. Just the daily games — plain puzzles, full connection
leaderboards, and a next-game navigator.

## Category

Fun (alt: Productivity)

## Detailed description

LinkedIn has one killer feature: the daily games. This extension removes
everything else.

🎮 GAMES-ONLY MODE (default)
• Every LinkedIn page redirects to the games hub — no feed, no notifications
• Global nav, messaging bubble, and banners are stripped: plain-faced puzzles
• Full connections leaderboard under every game: ranks, names, times, 💎 flawless
• Your solve time for each game, at a glance

🐵 SHOW-LINKEDIN MODE
One click ("Show LinkedIn") brings normal LinkedIn back — with a slim,
LinkedIn-styled game bar on top of every page: all 8 games, today's ✓ and
times, and the next unplayed game highlighted. One click to hide it all again.

Works with Queens, Tango, Zip, Mini Sudoku, Pinpoint, Crossclimb, Patches, and
Wend. Log in as usual — auth pages are never touched.

Private by design: no permissions beyond linkedin.com, no data collected, no
external servers. Scores and leaderboards come from LinkedIn's own API using
your existing session, exactly like the normal games pages do.

Not affiliated with or endorsed by LinkedIn.

## Publishing setup (one-time)

1. Pay the $5 developer fee at https://chrome.google.com/webstore/devconsole
2. Create the item manually once (upload `dist/linkedin-is-for-gaming.zip` from
   `npm run build`), fill this listing in, submit for review.
3. For CI publishing, generate Chrome Web Store API credentials
   (client_id/client_secret/refresh_token):
   https://github.com/fregante/chrome-webstore-upload-keys
4. Add GitHub repo secrets: CWS_EXTENSION_ID, CWS_CLIENT_ID, CWS_CLIENT_SECRET,
   CWS_REFRESH_TOKEN.
5. Release: bump "version" in manifest.json + package.json, then
   `git tag v<version> && git push --tags` — the workflow builds, uploads, and
   publishes.

## Privacy questionnaire answers (dev console)

- Single purpose: "Reduces linkedin.com to its daily-games section."
- Permissions justification: content scripts on linkedin.com only (no API
  permissions requested); required to restyle pages and read the user's own
  game results.
- Data collection: none. See `store/privacy.md`.
- Remote code: none.
