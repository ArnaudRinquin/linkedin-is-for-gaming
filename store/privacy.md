# Privacy policy — LinkedIn is for Gaming

Last updated: 2026-07-17

This extension does not collect, store, transmit, or sell any personal data.

- It runs only on linkedin.com pages.
- It requests no Chrome extension permissions (no tabs, storage, history, etc.);
  it only injects content scripts and styles into linkedin.com.
- Game scores and leaderboards are fetched from LinkedIn's own API using your
  existing LinkedIn session, identically to what the LinkedIn games pages
  themselves do. Nothing leaves your browser.
- The only thing the extension persists is a single on/off preference, stored as
  a first-party cookie on linkedin.com in your own browser.
- No analytics, no external servers, no remote code.
